# Desafio Target - Questão 3

Implementação em C# para cálculo de juros com base no valor informado e na data de vencimento.

## Regra do desafio

- Considera 2,5% ao dia de atraso.
- Se a data de vencimento for hoje ou futura, não há juros.
- O cálculo utiliza juros simples sobre o valor informado.

## Executar

```bash
dotnet run
```

## Entrada

O programa solicita:

- valor original
- data de vencimento no formato `dd/MM/yyyy`

## Saída

O programa exibe:

- valor original
- valor dos juros
- valor atualizado
